MCA203P AS-05 — Solved Java Programs

Contains 20 separate Java source files for Q1-Q20 and one combined PDF.
Compile/run each file independently. Example:
  javac StudentMain.java
  java StudentMain

Note: Q4 and Q7 both specify a public Main class named PatientMain, so they are saved with
distinct filenames PatientMain_Q4.java and PatientMain_Q7.java in this folder. To compile either
file, rename the selected file to PatientMain.java first, or use the combined PDF/source code.
The same class names across questions are intentional because each question is a separate program.
